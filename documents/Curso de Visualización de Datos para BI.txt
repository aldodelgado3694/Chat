## Técnicas de visualización

1. Precision de datos y cuidado de no sobrecargar vistas
2. Estética visual > Mantenerla y que sean agradables
3. Segmentación por personal dirigido > Alimentar con datos dependiendo de tonicidad o interés.
4. Estructura y enfoque > Determina publico objetivo, Estructura los datos para presentarlos efectivamente conforme al publico.
5. Figuras con clasificación > No usar graficas de tendencia con graficas de segmentación.

3. Datos como atributo

## Diseño de datos

1. Estructura
- Jerarquía de información y visual
- Diseño en F inicia en la parte superior izquierda has la derecha y bajar como en F
- Diseño en Z recorres desde la parte superior, sigues en cuerpo de Z relacionada con la primer parte, al final el cierre de la información e la base de la Z
2. Estética
- Tipología de color, no combines colores que no contrasten. Juega con la entidad corporativa.
- Topografía, no uses letra no legibles, juega con tamaños de fuentes y letras.
3. Usabilidad
- Que sea útil y claro, contesta preguntas con las tablas 
4. Accesibilidad
- Perceptible > Interesados pueden usar e interactuar con la información
- Operable > Si son dinámicas, debe de sr sencillo para el visualizador
- Comprensible > Se entendible por los diferentes stakeholders
- Robusto > La información debe ser confiable, veraz y oportuna

## Modelado de datos

1. Usar DM para datos de dimensión
- dmInventario
- Es una tabla relacionada, puede ser tabla de clientes, productos
2. Fact para tabla de datos de hechos
- FactProductos
- Es la tabla con el histórico de los datos, contiene toda la información que vamos a analizar y trabajar, aquí se usara la tabla de dimensión por ejemplo con el ID de cliente o de producto.

# Dashboards efectivos

1. Indexado de datos
- Tabla de dimensión es de 1 a Muchos "1:*"
- Es importante configurar esto en la pestaña de modelado
2. Visualización de datos
- Definir el publico objetivo, Definir donde se visualizara y modificar el tamaño del lienzo.
- Tipos de gráficos
    - Barras y columnas > Son buenos para segmentar, agrupar, compilar, por ejemplo genero con una medida de números, tienen eje X y Y
    - Lineal y ares > Como el primero pero nos permite ver una tendencia en el tiempo, por ejemplo seguir la temperatura en un lugar.
    - Cascada, embudo y dispersión > Permite ver correlación entre datos, comparar datos en eje x y y.
    - Grafico circular, anillos y rectángulos > Ventas por mes por día, ver los volúmenes de los datos. Ayuda a visualizar la porción de cada genero.
    - Mapas > Espaciar datos por localización, por ejemplo ver en que tienda se vendió mas en un mapa.
    - Medidor, tarjeta y KPI > Nos da impacto , por ejemplo metas, Cuanto se vendió, inventario restante.
    - Segmentación de datos > Dar dinamismo a los datos.
    - Tabla y matriz
    - Objetos visuales de IA

## Mejorando las visualizaciones

1. herramientas externas
- Podemos mejorar la vista de nuestros dashboards
- PowerPoint para el uso de imágenes en Power BI, edición de imágenes y guardado como SVG para agregar a Power BI.
2. Mantener relevancia en colores
- Usar herramientas como color Hunt para usar los colores que mejor se adapten entre ellos
3. Mantener la relación de texto
- Cambiar fuentes, que se vea bien el grafico. 
4. Contexto de los datos
- Cambiar títulos de gráficos para que la información sea coherente
- Cambiar formatos para visualizar los datos como son por ejemplo poner signo de pesos o de porcentaje.
5. Resaltar datos.
- Poner en negrita la información para dar fuerza a los datos que son importantes para el usuario.
